# Statistical Modeling of Zoonotic Virus Pathogenicity and Human Infection Risk Using Machine Learning

## Overview

This MSc Statistics project investigates the statistical modeling of zoonotic virus pathogenicity and human infection risk using machine learning and quantitative methods.

## Objectives

- Analyze factors associated with zoonotic virus pathogenicity.
- Investigate variables related to human infection risk.
- Apply statistical and machine-learning methods to the data.
- Evaluate model performance and interpret important predictors.

## Methods

- Exploratory Data Analysis
- Statistical modeling
- Feature analysis
- Machine learning
- Model evaluation
- Data visualization
